Provide access_token to registered clients/services. Issue OAuth2 compliant authorization token.

AUTHZ-TOKN : /oauth2/client/token


Client integration notes:
1. This end point is in compliance with OAuth2 RFC 6749 to authenticate registered confidential clients with grant_type=client_credentials over HTTPS channel.
2. Clients MUST obtain client credentials (client_id with client_secret, or a registered key pair) as part of client registration.
3. Clients authenticate with ONE of the following methods; implementations MUST support at least one and SHOULD document which they support:
a. client_secret_basic: HTTP Basic with client_id / client_secret (RFC 6749 section 2.3.1).
b. client_secret_post: client_id and client_secret in the request body (RFC 6749 section 2.3.1).
c. private_key_jwt: client_assertion_type and client_assertion in the request body (RFC 7523).
d. tls_client_auth: mutual TLS client certificate (RFC 8705), with client_id in the request body.
e. Bearer token in the Authorization header, for implementations that already issue a registration or bootstrap token.
4. Clients MUST ensure to secure sensitive information e.g, client_secret, private keys, access_token, etc.,
5. RFC 6749 section 4.4.3 recommends NO support for refresh access_token.
6. Successfully authenticated clients SHALL receive bearer type access_token.
7. Clients MUST set HTTP "Authorization: Bearer " in HTTP header to access any spdci compliant api end points.
8. Rest end points SHALL return http status 401 when access_token is invalid or expired.

grant_type
required
string
Value: "client_credentials"

Value must be set to client_credentials

client_id
string

The client identifier issued to the client during the registration process described by RFC 6749 Section 2.2. Required for client_secret_post and tls_client_auth; omitted when using HTTP Basic.

client_secret
string

Client secret shared with the client during registration or regular rotation. Used only for client_secret_post (RFC 6749 Section 2.3.1).

client_assertion_type
string
Value: "urn:ietf:params:oauth:client-assertion-type:jwt-bearer"

Used only for private_key_jwt (RFC 7523 Section 2.2).

client_assertion
string

Signed JWT identifying the client. Used only for private_key_jwt (RFC 7523 Section 2.2).

scope
string (OidcScope)

OIDC complaint auth tokens issued by an authorization service for OAuth2, OIDC complaint clients.
